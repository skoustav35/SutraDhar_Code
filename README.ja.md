### インストール

```bash
# YOLO
curl -fsSL https://sutradhar.ai/v2/install | bash

# パッケージマネージャー
npm i -g @sutradhar/cli@latest      # bun/pnpm/yarn でもOK
brew install anomalyco/tap/sutradhar-v2 # macOS と Linux（推奨。常に最新）
brew install sutradhar              # macOS と Linux（公式 brew formula。更新頻度は低め）
sudo pacman -S sutradhar            # Arch Linux (Stable)
paru -S sutradhar-beta              # Arch Linux (Latest from AUR)
mise use -g sutradhar               # どのOSでも
nix run github:anomalyco/sutradhar  # Nix
```

> [!TIP]
> インストール前に 0.1.x より古いバージョンを削除してください。

### デスクトップアプリ (BETA)

Sutradhar はデスクトップアプリとしても利用できます。[sutradhar.ai/download](https://sutradhar.ai/download) からダウンロードしてください。

| プラットフォーム      | ダウンロード                       |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `sutradhar-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `sutradhar-desktop-mac-x64.dmg`     |
| Windows               | `sutradhar-desktop-win-x64.exe`     |
| Linux                 | `.deb`、`.rpm`、または AppImage    |

```bash
# macOS (Homebrew)
brew install --cask sutradhar-desktop
```

#### インストールディレクトリ

インストールスクリプトは、Sutradhar を `$HOME/.sutradhar/bin` にインストールします。

### Agents

Sutradhar には組み込みの Agent が2つあり、`Tab` キーで切り替えられます。

- **build** - デフォルト。開発向けのフルアクセス Agent
- **plan** - 分析とコード探索向けの読み取り専用 Agent
  - デフォルトでファイル編集を拒否
  - bash コマンド実行前に確認
  - 未知のコードベース探索や変更計画に最適

また、複雑な検索やマルチステップのタスク向けに **general** サブ Agent も含まれています。
内部的に使用されており、メッセージで `@general` と入力して呼び出せます。

[agents](https://sutradhar.ai/docs/agents) の詳細はこちら。

### Sutradhar の上に構築する

Sutradhar に関連するプロジェクトで、名前に "sutradhar"（例: "sutradhar-dashboard" や "sutradhar-mobile"）を含める場合は、そのプロジェクトが Sutradhar チームによって作られたものではなく、いかなる形でも関係がないことを README に明記してください。
