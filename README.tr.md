### Kurulum

```bash
# YOLO
curl -fsSL https://sutradhar.ai/v2/install | bash

# Paket yöneticileri
npm i -g @sutradhar/cli@latest      # veya bun/pnpm/yarn
brew install anomalyco/tap/sutradhar-v2 # macOS ve Linux (önerilir, her zaman güncel)
brew install sutradhar              # macOS ve Linux (resmi brew formülü, daha az güncellenir)
sudo pacman -S sutradhar            # Arch Linux (Stable)
paru -S sutradhar-beta              # Arch Linux (Latest from AUR)
mise use -g sutradhar               # Tüm işletim sistemleri
nix run github:anomalyco/sutradhar  # Nix
```

> [!TIP]
> Kurulumdan önce 0.1.x'ten eski sürümleri kaldırın.

### Masaüstü Uygulaması (BETA)

Sutradhar ayrıca masaüstü uygulaması olarak da mevcuttur. [sutradhar.ai/download](https://sutradhar.ai/download) adresinden indirebilirsiniz.

| Platform              | İndirme                            |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `sutradhar-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `sutradhar-desktop-mac-x64.dmg`     |
| Windows               | `sutradhar-desktop-win-x64.exe`     |
| Linux                 | `.deb`, `.rpm` veya AppImage       |

```bash
# macOS (Homebrew)
brew install --cask sutradhar-desktop
```

#### Kurulum Dizini (Installation Directory)

Kurulum betiği, Sutradhar'u `$HOME/.sutradhar/bin` dizinine kurar.

### Ajanlar

Sutradhar, `Tab` tuşuyla aralarında geçiş yapabileceğiniz iki yerleşik (built-in) ajan içerir.

- **build** - Varsayılan, geliştirme çalışmaları için tam erişimli ajan
- **plan** - Analiz ve kod keşfi için salt okunur ajan
  - Varsayılan olarak dosya düzenlemelerini reddeder
  - Bash komutlarını çalıştırmadan önce izin ister
  - Tanımadığınız kod tabanlarını keşfetmek veya değişiklikleri planlamak için ideal

Ayrıca, karmaşık aramalar ve çok adımlı görevler için bir **genel** alt ajan bulunmaktadır.
Bu dahili olarak kullanılır ve mesajlarda `@general` ile çağrılabilir.

[Ajanlar](https://sutradhar.ai/docs/agents) hakkında daha fazla bilgi edinin.
